::: tip Turn on auto-update
Claude Code does not auto-update third-party marketplaces by default, so installed plugins stay on the version you installed. To get new releases automatically, run `/plugin`, open **Marketplaces**, select `b2c-developer-tooling`, and choose **Enable auto-update**. Claude Code then checks for updates when a session starts; run `/reload-plugins` or start a new session to load them.
:::
