Assistants that support the MCP Skills extension can now list and load the server's skills directly. MCP skills are renamed with a `b2c-mcp-` prefix (for example `skill://mcp/b2c-mcp-scapi/SKILL.md`), and the server skill now opens with an index of which skill covers each task.
