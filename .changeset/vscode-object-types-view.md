New **Object Types** view to browse system object attributes, enum values, and attribute groups, copy attribute IDs, and export metadata XML. Edit and save a custom attribute definition to apply it to the instance after a confirmation, including enum values through a site import, or create one with **New Custom Attribute...**. Add, edit, remove, or set the default enum value from the context menu without editing JSON. The SCAPI sidebar is now **B2C-DX: APIs** and holds both the API Browser and Object Types.
