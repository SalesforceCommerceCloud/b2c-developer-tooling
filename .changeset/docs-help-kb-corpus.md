Docs search now covers Salesforce Help Knowledge Articles for B2C Commerce, so you and your AI agents can find answers to common troubleshooting questions, known issues, and how-tos (for example, "orders stuck in created status" or "Hyperforce code upload certificate") right alongside the developer docs. Try `b2c docs search <query> --category help-kb`, or read an article with `b2c docs read help-kb/<article-number>`.
