Add `b2c commands search <query>` to find the CLI command for a task by keyword (for example `b2c commands search "reset sandbox" --json`). It complements `b2c docs search`, which searches documentation. The SDK exports `CommandSearchIndex` from `@salesforce/b2c-tooling-sdk/cli`.
