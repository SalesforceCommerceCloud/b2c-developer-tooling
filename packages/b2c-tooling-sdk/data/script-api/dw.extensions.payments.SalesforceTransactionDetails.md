# Class SalesforceTransactionDetails

- [TopLevel.Object](TopLevel.Object.md)
  - [dw.extensions.payments.SalesforceTransactionDetails](dw.extensions.payments.SalesforceTransactionDetails.md)

Base class transaction details to a payment transaction.


Some payment types have additional details available. Details to those payment transactions will be of a specific
subclass of this class like [SalesforceCardTransactionDetails](dw.extensions.payments.SalesforceCardTransactionDetails.md) or [GiftCardTransactionDetails](dw.extensions.payments.GiftCardTransactionDetails.md).
